Privacy basics
  • Private bucket; files are not public.
  • Database and storage policies restrict access to the signed-in owner.
  • Connection values are saved in this browser only.
  • Sign out when using a shared device.

Initial setup

  1. Create a Supabase project.
  2. Run the included supabase_setup.sql in SQL Editor.
  3. Copy Project URL and the publishable key (or legacy anon key) into the fields above.
  4. Create an account / sign in. If email confirmation is enabled, confirm your email.
  5. Create a workbook. It will be stored in the private sanzone-excel bucket.

The SQL setup creates the private bucket, file metadata table and owner-only Row Level Security policies.
